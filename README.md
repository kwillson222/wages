# Employee Wages in California

Data sourced from the Quarterly Census of Employment and Wages (QCEW), [available for download on California Open Data.](https://data.ca.gov/@california-employment-development-department/quarterly-census-of-employment-and-wages/r/119eef38-3b59-499f-8f7c-9bea4768469d)
